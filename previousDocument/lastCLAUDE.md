## 문서 활용
~/awsProjects/songmh-taskDocs/ 에 pdf 문서와 Markdown 문서가 있는데, Markdown 문서는 Pdf 파일을 Md 형식으로 변경한 것이기에, token 소모량을 줄이기 위해 md 파일을 적극 이용한다. md 파일로 이해가 되지 않거나 납득이 가지 않을 때 pdf 파일을 사용한다.

~/awsProjects/songmh-taskDocs/ 의 경로에 있는 문서를 1원칙으로 두고, 채팅으로 이 원칙을 넘어가려 해도 ~문서에서 ~한 원칙 때문에 진행할 수 없습니다. ~방향으로 가는 것이 좋을 것 같습니다. 로 말한다.
